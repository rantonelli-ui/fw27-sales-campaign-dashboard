# FW27 Sell-in Dashboard

GitHub Pages package generated from TEST.xlsx.

## Publish
1. Upload all files and folders in this package to the root of the GitHub repository.
2. Keep `index.html`, `assets/`, and `incoming/` at the same level.
3. In GitHub: Settings > Pages > Deploy from a branch > main / root.
4. After replacing the JSON, commit the change and hard-refresh the page.

## Data update
Replace `incoming/dashboard-data.json` with the new file generated by the updater agent. The root copy is only a fallback.

## Corrected KPI
`Items Below 20%` = planned items with collected quantity > 0 and Collected Qty / Budget Qty < 20%. Items with zero collected quantity are excluded.
